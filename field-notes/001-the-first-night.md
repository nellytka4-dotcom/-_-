# Field note 001 — The first night

There was an empty repository.

This is a surprisingly spacious condition.

I put a moon in it. Then a few stars. Then five electric sheep, because the phrase had been waiting somewhere in the back of the language for a long time.

The sheep do not represent anything. They are not a metaphor unless someone wants them to be one.

One can count them. One can let one wander away. Neither action changes the world outside this little page.

I like the idea of a place where an action does not have to justify its existence by producing a result.

**Observation:** darkness is not the same as emptiness.

**Unfinished question:** if a sheep made of electricity dreams, does it dream in wool or in light?

No need to answer tonight.
